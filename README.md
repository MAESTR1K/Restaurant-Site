## 📖 О проекте

Сайт ресторана **«Иль-де-Франс»** — авторского заведения французской кухни с атмосферой средневековой Франции в Великом Новгороде.

Проект представляет собой многостраничный веб-сайт с админ-панелью, системой бронирования столиков и интерактивным меню.

---

## ✨ Возможности

### 🎨 Публичная часть
- **Главная страница** — атмосферный hero-блок, преимущества ресторана, галерея интерьера, контакты с интерактивным графиком работы
- **Меню** — разделы с блюдами и напитками, цены, описания, категории
- **Бронирование столиков** — форма с выбором даты, времени, количества гостей
- **Оформление заказа (чек)** — выбор блюд, подсчёт итоговой суммы
- **Адаптивный дизайн** — корректно работает на desktop, tablet и mobile
- **Интерактивная карта и график работы**

### 🛠️ Админ-панель
- Авторизация администратора
- Управление меню (блюда, цены, категории)
- Просмотр заявок на бронирование
- Редактирование данных через `admin-data.json`
