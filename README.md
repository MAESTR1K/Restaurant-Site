## 📖 О проекте

**«Иль-де-Франс»** — сайт авторского ресторана французской кухни с атмосферой средневековой Франции в Великом Новгороде.

Проект включает: публичный сайт (главная, меню, бронирование, чек), **систему онлайн-бронирования**, **формирование заказа с печатью чека**, **панель администратора** с дашбордом, аналитикой и управлением меню.

> 🎓 Проект выполнен в рамках технического задания. Студент: М.Д. Маслов, группа 5996.

## ✨ Возможности

### 🌐 Публичная часть

- **Главная страница** — hero-блок, преимущества, галерея интерьера с модальным просмотром
- **Меню** — категории блюд (закуски, основные, десерты), интерактивный выбор
- **Бронирование столика** — форма с маской телефона, валидация, выбор даты и времени
- **Формирование заказа** — корзина на localStorage, подсчёт итоговой суммы
- **Печать чека** — генерация чека с логотипом и составом заказа (через CSS print)
- **Интерактивная карта** — встроена Яндекс.Карта с оверлеем адреса
- **График работы** — динамическое отображение статуса (открыто/закрыто)

### 🛠️ Админ-панель

- **Авторизация** — вход по логину/паролю (demo: `admin` / `admin123`)
- **Дашборд** — статистика дня: заказы, посетители, выручка, загрузка столиков
- **Управление меню** — CRUD блюд: добавление, редактирование, удаление
- **Управление заказами** — вкладки по статусам (активные / завершённые / отменённые)
- **Управление бронями** — фильтры по дате и статусу, редактирование, удаление
- **Аналитика** — графики на Chart.js: продажи, посетители, выручка
- **Экспорт отчёта** — генерация отчёта за день
- **Floating-уведомления** — о новых заказах
